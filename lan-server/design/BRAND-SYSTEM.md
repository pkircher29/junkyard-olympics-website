# Junkyard Olympics Surface System

Canonical source: `assets/tshirt-brand-reference.png`.

## Surface choices
- Participant: Configure → Monitor. A called match dominates; event enrollment and actions follow.
- Organizer/Cannon: Operate. Dense action queues, explicit states, audit visibility, touch controls.
- Station/TV: Monitor. Across-yard hierarchy, high contrast, minimal interaction.
- Print: emergency reference packet. Ink-safe, linear sections, repeated headers, handwriting space.

## Tokens
- Soot `#171814`; dirty cream `#F1E3C1`; rust `#A73520`; flame orange `#E65F1A`; warning yellow `#F5A623`; faded olive `#667342`; steel `#88908A`.
- Display: locally available Impact/Arial Narrow fallback, italic where brand-forward; controls and metadata use Courier New.
- Hard 3–6px outlines, offset shadows, square corners, dashed ledger rules.

## Motifs
Halftone pinpricks, rough diagonal score marks, flame stripe, inspection labels, taped cards, thick rings suggesting tires/targets. Texture is CSS-only and never behind small text at high opacity.

## Accessibility
44px touch floor; visible yellow focus rings; high contrast; status never encoded by color alone; semantic tables and controls; reduced-motion support; 11pt+ print copy; TV copy scaled for distance.

## Slop audit
Final score: **0/10**. No tech gradients, indigo accents, generic feature tiles, accent rails, blur, monument filler metrics, icon toppers, center-stack composition, default Inter, or wrong-surface layouts.
